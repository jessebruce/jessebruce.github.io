# jessebruce.github.io

Personal site for Jesse Bruce, served by GitHub Pages at
https://jessebruce.github.io.

It is a single static page — `index.html` with inline styles — plus a résumé
PDF and a set of self-hosted web fonts (Inter, Space Grotesk, and JetBrains
Mono, all under the SIL Open Font License). There is no build step, no
framework, no JavaScript, and no external requests: the page is the complete
artifact, and opening `index.html` locally renders it exactly as published.

This repository is a publish target. It holds the current version of the site
and nothing else; the page is authored and maintained elsewhere and pushed here
as a single commit whenever it changes.
